# Bundled fonts

Vellum bundles three font families so the multilingual UI demo does not depend on
host fonts. This host has Latin fonts but no CJK or Arabic text font.

All files were pinned from Google Fonts commit
`cc5661d43cd4f9aad5567033a8e15ca28dc35c86`.
